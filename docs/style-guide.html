Live states — motion demo

Each button auto-loops through rest → hover → active on a 3s cycle.

Motion principles

  • Duration: 150ms for bg / border / color · 100ms for scale (snappy press).
  • Easing: cubic-bezier(0.16, 1, 0.3, 1) for lift · ease for color.
  • Hover lift: translateY(-1px) only for primary buttons.
  • Active press: scale(0.98) on primary buttons.
  • Reduced motion: respect prefers-reduced-motion: reduce.

Behavior modifiers — pulse & ring

Use sparingly. A pulse should mean "real-time active" (live mode, streaming, recording). A ring emphasizes without animating. More than 2 pulsing dots on screen at once = visual noise.
Default (static)
Live Unread
No animation. Cheapest visually, fine for most cases.
Pulse · real-time
Live Urgent
Outward pulse at 2s cycle. Reserved for real-time signal ("streaming," "listening," "recording," breaking urgency).
Ring · emphasis
Connected Online
Static soft glow. Emphasizes without motion — better for sustained states (user online, system connected).

Section 05 — Cards
Locked ✓
The card family
Four decisions resolved. Cards are the primary content surface — unified shape with buttons/inputs, physical separation from the page via shadow, signaling interactivity through color shift only, and a prescriptive CardHeader primitive for consistency.
Rule Value
Shaperounded-lg (8px) — unified with buttons + inputs (decision 1B)
Containerborder border-white/[0.08] + shadow: 0 2px 6px rgba(0,0,0,0.25) — Stripe-style subtle shadow (decision 2C)
Surface#0e1a2e default · #0a1628 elevated (dialog/popover) · tinted for special (quote panel)
Paddingp-6 (24px) default · p-4 (16px) dense · p-8 (32px) hero/stat
ElevationTwo tiers — flat (in-page, default) · elevated (dialogs/popovers). Interactive cards signal via border-brighten + bg-shift only, no shadow lift (decision 3B)
HeaderPrescriptive <CardHeader icon title subtitle trailing /> primitive (decision 4A)

Elevation scale — two tiers

Flat (default)
In-page content card
border + shadow 0 2px 6px /25
Elevated
Dialog · popover · sheet
shadow 0 12px 32px /40
Flat carries a gentle 2px shadow so cards read as real objects sitting on the page (Stripe-style). Elevated is reserved for cards that literally float above the page (dialogs, popovers, menus). Interactive cards don't change elevation — they signal interactivity by brightening their border and bg, not by lifting.
