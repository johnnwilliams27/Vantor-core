# Latitude Global Finance — independent concept demo

This branch is a one-off visual rebrand of the self-contained Vantor public demo. It is **not** an official Latitude product, affiliated demo, or representation of existing Latitude functionality.

- Source branch: deploy/public-demo (original Vantor demo unchanged)
- Prototype branch: demo/latitude-concept-2026
- Vercel project: latitude-concept-demo
- Root directory: demo-site
- Public interface route: /demo

The concept uses a light blue/white palette inspired by Latitude's public visual identity. All records, accounts, balances, charts and actions are fictional and browser-local. It makes no banking, stablecoin, or financial network calls.
